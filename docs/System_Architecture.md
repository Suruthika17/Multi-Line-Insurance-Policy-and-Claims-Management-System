# System Architecture

The system follows a Salesforce-based layered architecture.

## User Layer

Users access the application through Salesforce Lightning Experience.

## Presentation Layer

Lightning Web Components provide dashboard and user interface functionality.

## Business Logic Layer

Apex Trigger and Apex Handler classes implement business rules and validations.

## Automation Layer

Salesforce Flows automate policy renewal, claim processing and payment reminders.

## Data Layer

Custom Salesforce Objects store customers, policies, claims, agents, payments and documents.

## Repository

GitHub is used for source-code and project documentation management.
